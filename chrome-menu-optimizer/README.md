# Chrome 书签菜单优化器 - 安装和使用指南

## 🚀 快速开始

### 安装步骤
1. 下载或克隆此项目到本地
2. 打开 Chrome 浏览器，访问 `chrome://extensions/`
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择项目文件夹
6. 确保扩展已启用

### 使用方法
1. 安装插件后，浏览器工具栏会出现插件图标
2. 点击插件图标打开设置弹窗
3. 开启"启用菜单自动换行"开关
4. 书签栏将自动变为网格排列模式

## 🔧 故障排除

### 问题1：书签栏没有变成横排
**可能原因和解决方案：**

1. **扩展未正确加载**
   - 检查 `chrome://extensions/` 页面，确保扩展已启用
   - 点击扩展的"刷新"按钮重新加载

2. **页面不支持content script**
   - 扩展只在 http/https 网页上工作
   - 不支持 chrome:// 等内部页面
   - 尝试在普通网页上测试

3. **样式被其他扩展覆盖**
   - 暂时禁用其他可能影响页面样式的扩展
   - 点击扩展图标中的"强制应用样式"按钮

4. **浏览器缓存问题**
   - 按 Ctrl+F5 强制刷新页面
   - 清除浏览器缓存

### 问题2：扩展图标点击无反应
**解决方案：**
- 检查扩展权限是否正确授予
- 重新加载扩展
- 重启浏览器

## 📋 功能说明

### 主要功能
- 🔄 将书签栏从单行布局改为多行网格布局
- 📏 自动调整书签项大小和间距
- 🎯 智能检测 Chrome 原生书签栏
- 🔧 可通过扩展图标开关控制
- ⚡ 支持强制应用样式功能

### 支持的元素
- Chrome 原生书签栏
- 带有 `class*="bookmark"` 的元素
- 带有 `id*="bookmark"` 的元素
- 带有 `role="toolbar"` 属性的工具栏
- 动态生成的书签内容

## 🔍 技术细节

### 工作原理
1. **CSS注入**：向页面注入强制网格布局样式
2. **DOM监听**：监听页面DOM变化，自动应用样式
3. **消息通信**：popup与content script之间的双向通信
4. **定期检查**：每5秒自动检查并重新应用样式

### 样式特点
- 使用CSS Grid布局实现多行排列
- 每个书签项最小宽度120px
- 自动填充可用空间
- 响应式设计，适应不同屏幕尺寸

## 💡 使用提示

1. **最佳实践**
   - 在普通网页上测试效果
   - 定期检查扩展是否正常工作
   - 遇到问题时使用"强制应用样式"功能

2. **兼容性**
   - 支持Chrome 88+版本
   - 支持基于Chromium的浏览器（如Edge）
   - 不支持Firefox等非Chromium浏览器

3. **性能优化**
   - 扩展会自动检测页面变化
   - 只在需要时应用样式
   - 对页面性能影响极小

## 🐛 已知问题

1. **某些网站可能不兼容**
   - 部分网站的CSS可能与扩展样式冲突
   - 可以尝试使用"强制应用样式"功能

2. **动态加载的书签**
   - 某些动态生成的书签可能需要手动刷新
   - 扩展会自动检测并应用样式
